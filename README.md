# 单词复习 · 听写练习

一个纯前端的英语单词复习网站：看中文提示写英文句子，逐词校验、彩色词性标注、真人发音，还能按主题刷区块链词汇。无需后端，打开即用。

**在线演示：** https://ustbmz.github.io/ENWord/

---

## 功能特性

### ✍️ 听写练习
- 根据中文提示逐词输入英文句子，实时标红拼错的单词
- **键盘操作**：`空格` 切换到下一个单词，`回车` 校验答案；答对后再按 `回车` 直接进入下一题
- 每题 3 次提示机会，卡住时可点击查看彩色词性标注和完整答案
- 一键朗读英文句子，支持上一题 / 下一题 / 重做
- 顶部进度条与底部状态栏（总词数 / 总句数 / 正确率）实时更新

### 📖 单词复习
- 词卡展示单词、释义、词性和例句语境
- 支持**词性筛选**（名词 / 动词 / 形容词 / 其他）与**主题筛选**（生活口语 / 区块链）叠加使用
- 点击卡片标记「已掌握」，再次点击可取消；点击朗读按钮听单词发音
- 每张词卡标注所属主题，区块链词汇用紫色区分

### 📊 学习统计
- 已学句数、答对句数、掌握单词数、正确率
- 各词性掌握进度条与最近学习记录
- 一键清空学习记录（不清除发音设置）

### ⚙️ 发音与音效设置
- 智能挑选系统英语音色（优先本地高质量音色），不再用中文语音硬读英文
- 可自选音色、调节语速与音调，支持试听后保存
- 打字 / 空格 / 回车 / 退格带机械键盘敲击声，可在设置里开关
- 所有设置保存在浏览器本地，下次打开自动生效

## 本地运行

项目是纯静态文件，无需安装依赖：

```bash
# 方式一：直接双击 index.html 用浏览器打开

# 方式二：启动本地服务（推荐，发音和本地存储表现更稳定）
python3 -m http.server 8000
# 然后访问 http://localhost:8000/
```

> 提示：发音功能依赖浏览器的 Web Speech API，建议使用 Chrome / Edge / Safari 最新版。

```

```

## 技术实现

- **原生 HTML / CSS / JavaScript**，零依赖、零构建，离线也能使用（除语音外）
- 发音：`speechSynthesis` + 智能英语音色选择
- 键盘音效：`Web Audio API` 实时合成，无需音频文件
- 进度保存：`localStorage`，数据仅存本机，不会上传
